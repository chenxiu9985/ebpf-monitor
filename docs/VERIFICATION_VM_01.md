## 防止误读的说明

1. 环境清单 `load_verified=false` 是 doctor() 静态能力清单的默认字段。真实采集通过及原始内核事件证明加载成功，不能用该字段否定 VM 实测。
2. 微基准 `limitation` 中“not the target VMware benchmark”由 `scripts/benchmark.py` 硬编码，沿用了旧描述。环境字段和用户说明表明本轮来自目标 VM；保留原数据不篡改，T36 中安排修复后续输出的环境说明。
3. 活动 LSM 明确不含 bpf，`bpf_lsm_active=false`；原始日志 `enforcement_enabled=false`、`denied=0`。本轮不能证明 LSM 拒绝生效。尚未发现 VM 专属 LSM 结果或新的完整 acceptance summary。
4. 当前 21 个文件与第二轮 WSL 归档 SHA-256 一致。VM 测试缺少运行时完整源码/依赖 manifest，因此不能倒推出“当前全部文件与当时二进制严格一致”。本次归档仅记录复制后的状态。
5. WSL 23.35% 与 VM 32.49% 属于不同环境；当前性能安排使用 VM 基线，但不能把差值解释为代码性能回退。
