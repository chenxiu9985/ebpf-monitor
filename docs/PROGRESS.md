## 环境与验收口径

目标环境为用户提供的 VMware / Ubuntu Server 24.04.3 / 6.8.0-136-generic x86_64 / 3.8 GiB / chenxiu UID=1000 / BCC 0.29.1+ds-1ubuntu7，见 `config/target.json`。正式实现使用 libbpf，不要求卸载 BCC。

历史本地实测为 Ubuntu 24.04 WSL、6.6.87.2-microsoft-standard-WSL2，约 7.4 GiB，clang 18、libbpf 1.3.0、Python 3.12.3。Windows Python 3.12.0 仅用于离线回归。不同内核、内存、磁盘和 PID namespace 的结果不得互相替代。

下表“本地通过”表示实现已有本地证据，不表示原任务全部验收标准在目标机通过。“部分”保留尚未覆盖的要求。

VM 初始基线：P95 245.39 ms、吞吐下降 32.49%。本轮批处理优化后：P95 240.01 ms，同二进制五轮对照吞吐下降 32.56% → 15.24%，含排空/退出 39.96% → 26.60%；活动 LSM 未更改。报告中的“本地通过”保留 WSL 专项证据含义。
